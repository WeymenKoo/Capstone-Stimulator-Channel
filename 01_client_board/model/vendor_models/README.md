# Vendor models

SPICE models downloaded from the manufacturers, kept as received. The simulations use the working copies in
`../client-board-models.lib` and `../client-board-channel-subcircuit.lib`.

| File | Part | Source |
|---|---|---|
| `MJD340.spice.txt`, `MJD350.spice.txt` | MJD340 NPN / MJD350 PNP, 300 V DPAK (Q2 / Q1) | Diodes Inc. |
| `BZX84C5V1.spice.txt` | BZX84C5V1 zener | Diodes Inc. |
| `BAS16.lib` | BAS16 switching diode, SOT-23 | vendor model (maker not named in the file) |
| `INA149_sbomc47.zip` | INA149 difference amplifier (TI SBOMC47) | Texas Instruments |
| `TLE2141_slom459a.zip` | TLE2141 op-amp, PSpice model and test circuit (TI SLOM459A) | Texas Instruments |
