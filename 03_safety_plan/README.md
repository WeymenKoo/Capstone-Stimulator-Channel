# 03_safety_plan: system architecture and Rev 2 safety loop (planning)

Planning material for the hardware safety loop planned for Rev 2 (trips and latch return, which Rev 1 does not have).
Not part of the Rev 1 board and not a safety sign-off.

| File | Contents |
|---|---|
| `01_system-architecture-and-fault-protection.pptx` | System architecture and fault-protection deck: grounding, isolation, fault cases, simulation results, decisions |
| `SAFETY_LOOP.md` | Safety-loop specification draft: trips, thresholds, latch and reset, open decisions |
| `FMEA.md` | FMEA table (skeleton, to be filled by the team) |
| `kicad/safety-loop.kicad_sch`, `kicad/safety-loop.pdf` | Block-level schematic of the loop (KiCad + PDF export) |

The deck's slide formatting was done with Claude (Anthropic's AI assistant); its content, the analysis and every
decision are the channel designer's.
